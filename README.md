# 🌱 EcoRide - Plateforme de Covoiturage Écologique

EcoRide est une application de covoiturage orientée écologie :
- **PHP API (backend)** avec JWT Auth, trajets, participations, avis, crédits.
- **React + Tailwind (frontend)** pour interface utilisateur.
- **Docker** (PHP + Apache + MySQL).
- **Emails** via PHPMailer.
- **Tests PHPUnit** pour la partie backend.
